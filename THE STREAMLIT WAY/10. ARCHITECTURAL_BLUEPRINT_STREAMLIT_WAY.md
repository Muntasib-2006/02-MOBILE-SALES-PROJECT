# 10. ARCHITECTURAL BLUEPRINT: THE STREAMLIT PIPELINE WAY

**Project:** Mobile Device & Telecom Retail Analytics  
**Methodology:** Python-Centric Modular Data Engineering & Server-Hosted Web Application  
**Execution Environment:** Streamlit Framework (`localhost:8501`)  

---

## 1. Executive Summary & Philosophy (ELI5)

This pipeline follows an enterprise modular data engineering pattern. Raw logs are cleaned with Pandas, modeled into a Kimball Star Schema with Fact and Dimension tables, scored using vectorized NumPy math, and hosted as a live interactive dashboard via Streamlit on `localhost:8501`.

## 2. Chronological Pipeline Sequence

1. **`1. Raw_...`**: Unmodified raw source data (Excel/CSV).
2. **`2. clean_data.py`**: Automated data cleaning, type casting, and validation script.
3. **`3. Cleaned_Mobile_Sales.csv`**: Standardized, clean master dataset.
4. **`4. build_star_schema.py`**: Dimensional modeling engine decomposing data into Fact & Dimensions.
5. **`5. Fact & Dim Tables`**: The landed relational star schema tables.
6. **`6. dax_numpy_metrics.py`**: High-performance vectorized calculation of DAX KPIs and ratios.
7. **`7. DAX_Formulas_and_Model.md`**: Business logic, DAX specifications, and measure definitions.
8. **`8. generate_matplotlib_charts.py`**: Matplotlib plotting engine for executive reporting.
9. **`9. app.py`**: Master Streamlit conductor hosting interactive slicers and charts.
10. **`10. ARCHITECTURAL_BLUEPRINT_STREAMLIT_WAY.md`**: This comprehensive operational dossier.

## 3. How to Launch
```powershell
streamlit run "9. app.py"
```
