```markdown
# 📱 Mobile Device & Telecom Retail Analytics Dashboard (v1.0.0)

We are proud to release **v1.0.0** of the **Mobile Sales Intelligence Project**, showcasing two contrasting paradigms for modern data delivery:

### 🌟 Architectural Highlights:
1. **The HTML Way (Zero-Dependency Monolith):**
   - Inlined single-file architecture (`2. Mobile_Sales_Dashboard.html`, 2.4 MB).
   - 100% confidential, zero server costs, and sub-50ms client-side GPU canvas rendering with Chart.js.
   - Includes Python data baking engine (`3. generate_offline_dashboard.py`).

2. **The Streamlit Way (Modular Enterprise Pipeline):**
   - Normalized Kimball Star Schema (`Fact_Mobile_Sales` + 5 Dimensions: Customer, Date, Location, Payment, Product).
   - High-performance vectorized DAX metric calculations (`dax_numpy_metrics.py`).
   - Interactive Streamlit application (`localhost:8501`) with multi-brand filtering and responsive data grids.

3. **Whitepaper Included:**
   - Read the architectural comparison: [`HTML_WAY_VS_STREAMLIT_WAY_ARCHITECTURAL_SHOWDOWN.pdf`](./HTML_WAY_VS_STREAMLIT_WAY_ARCHITECTURAL_SHOWDOWN.pdf).

### 🚀 Quickstart:
- **Instant HTML View:** Double-click `THE HTML WAY/2. Mobile_Sales_Dashboard.html` in Chrome/Edge.
- **Run Streamlit:** `pip install -r requirements.txt && streamlit run "THE STREAMLIT WAY/9. app.py"`
```
